---

Analiza el diseño del sitio web del proyecto actual revisando el código CSS y JSX/HTML. Proporciona una crítica detallada evaluando:

1. **Jerarquía visual** — ¿El contenido más importante es prominente? ¿Los encabezados, CTAs y precios se destacan correctamente?
2. **Paleta de colores** — ¿Los colores son consistentes, accesibles y transmiten la identidad del negocio?
3. **Tipografía** — ¿Los tamaños, pesos y familias de fuente son legibles y consistentes?
4. **Usabilidad** — ¿La navegación es intuitiva? ¿Las acciones clave (reservar, contactar) son fáciles de encontrar?
5. **Consistencia** — ¿Los estilos, espaciados y componentes se repiten de forma coherente?
6. **Responsividad** — ¿El diseño funciona bien en móvil y desktop?
7. **Accesibilidad** — ¿El contraste de colores es suficiente? ¿Los textos son legibles?
8. **Primeras impresiones** — ¿El hero comunica claramente qué es el negocio?

Para cada punto:
- Indica qué está bien
- Indica qué se puede mejorar
- Propón el cambio concreto en código (CSS o JSX)

Al final da un resumen con las 3 mejoras más impactantes a implementar primero.
